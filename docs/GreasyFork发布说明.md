把英文网页的段落翻译成中文，显示在原文**上方或下方**，形成双语对照。原文完整保留，页面结构不被替换，代码块和命令不会被翻坏。主要面向 GitHub 与纯英文外网，中文网站默认自动跳过。

## 功能

- **双语对照**：译文以独立行插入英文段落上方或下方，带浅色底与「译」标记；点击译文可淡化，方便随时对照原文。`Alt+P` 一键切换上/下位置。
- **自动识别网页**：读取 `html[lang]`、meta language 并统计正文中文字符占比，识别站点类型（GitHub / GitHub Pages / GitHub Raw / 问答社区 / 技术文档 / 普通网站）与 GitHub 页面类型（代码页、Issue、PR、Discussion、Wiki、仓库页）。中文页面自动跳过；GitHub 系站点豁免中文检测，Issue 里混有中文评论时英文部分照译。运行范围可切「自动 / 仅白名单站点 / 所有网站」，白名单与中文占比阈值均可修改。统计语言时会扣除脚本自己注入的设置面板与译文，避免误判。
- **GitHub 专项适配**：跳过代码页 `blob-code`、diff 行、代码块、Monaco/CodeMirror 编辑器、文件名、徽标；只翻译 `main` / `article` / `.markdown-body` / 评论正文等正文容器。监听 `turbo:load`、`pjax:end`、`popstate` 并轮询 URL，GitHub 无刷新跳转时自动清旧译文、重新识别、重新翻译。
- **内联代码原样保留**：`Run npm install to ...` 译为「……运行 npm install ……」。内联代码、@用户名、commit hash 先转占位符再送翻译，译后还原；本地小模型改写了标记也能按数字锚点容错还原。
- **滚动持续补翻**：边滚边补扫遗漏段落，覆盖懒加载观察器漏触发、折叠内容展开、长页面超出单轮 300 段上限、以及正文延迟渲染等场景；设置里可关闭「滚动时补翻遗漏段落」。
- **限流自动恢复**：有道 411 触发 30 秒冷却时状态栏显示倒计时，冷却结束自动补翻限流期间滚动过的内容，无需刷新；译文为空/请求失败的段落会退避重试，不会永久空白。
- **验证页 / 骨架屏自动重判**：Cloudflare「请稍候… / 正在进行安全验证」这类中文占位页不会被误判为中文站，正文渲染后自动重判并开始翻译。
- **其它**：浮动「译」按钮默认在左下角（可一键切回右下角），采用半透明毛玻璃质感，静置时透出页面内容、鼠标悬停或展开设置时变清晰；设置面板同样为半透明玻璃风格并适配深色模式。另有动态加载内容自动补翻、只翻译视口附近内容、跨页面译文缓存、划词翻译、站点黑名单、亮/暗配色、Tampermonkey 右键菜单。

## 翻译源

| 源 | 配置 | 说明 |
|---|---|---|
| 网易有道（默认） | 无需配置 | `aidemo.youdao.com` 官方演示接口，国内直连、免注册。存在频率风控（错误码 411），脚本已做串行限速（1.4 秒/批）、批量合并、缓存与失败退避 |
| 百度翻译开放平台 | 填 appid + 密钥 | 需自行到 fanyi-api.baidu.com 免费申请，稳定无限流，MD5 签名已内置 |
| 本地离线服务 | 填接口地址 | 兼容 LibreTranslate 协议，数据不出本机 |
| 本地大模型 | 协议 + 地址 + 模型名 | 支持 Ollama / OpenAI 兼容接口（如 LM Studio），质量可超过在线接口 |

「失败自动回退」默认开启：主源失败时依次尝试本地服务 → 百度（已填密钥）→ 有道。多行文本合并为一批请求，译文行数严格对齐，不一致时自动降级逐条翻译。

> 有道默认源使用其官方演示接口，仅供轻量使用，可能被限流。需要长期稳定建议配置百度开放平台，或改用本地离线服务 / 本地大模型。

## 安装与使用

1. 安装 Tampermonkey（或 Violentmonkey / 脚本猫），把本脚本添加到新脚本并保存。
2. 首次访问英文页面时会弹出跨域访问授权（`@connect`），点「允许」；脚本需要向所选翻译接口发送请求。
3. 打开 GitHub 的 README、Issue、文档页等，左下角出现「译」按钮，1～3 秒后显示译文。点按钮展开设置面板，顶部会显示当前页面的自动识别结果与跳过原因；「图标位置」可把「译」按钮切回右下角。
4. 翻译本地 `file://` 网页时，需在浏览器扩展管理里给 Tampermonkey 开启「允许访问文件网址」。
5. **不想安装油猴？** 仓库另提供功能相同的 Chrome 扩展（Manifest V3）：到 [Releases](https://github.com/ljp801005-tech/github-en2zh-bilingual/releases/latest) 下载 `github-en2zh-bilingual-chrome-v*.zip`，解压后在 `chrome://extensions` 打开「开发者模式」→「加载已解压的扩展程序」选中该目录即可，已打开的标签页刷新一次生效。扩展与脚本版共用同一套代码，但配置与译文缓存相互独立。

快捷键：`Alt+T` 开启/暂停 · `Alt+P` 译文上/下切换 · `Alt+Enter` 立即翻译本页（可强制翻译被自动跳过的页面） · `Alt+S` 划词翻译（需先在设置中开启）。

## 隐私与权限

- 脚本使用 `@match *://*/*` 与 `file:///*`，是因为「纯英文外网」没有固定域名清单；默认只在站点白名单或判定为纯英文的页面上工作，可收紧为「仅白名单站点」。
- `@connect` 声明了 `aidemo.youdao.com`、`fanyi-api.baidu.com`、`localhost`、`127.0.0.1` 与 `*`。`*` 用于允许用户填写任意本机 / 局域网翻译服务地址；脚本只向**当前所选翻译源**的地址发请求，不向其它域名发送页面内容。
- **在线源会把需要翻译的英文文本发送给网易有道或百度**；选择本地离线服务或本地大模型时，数据完全不出本机。
- 译文缓存保存在浏览器本地（`GM_setValue`，最多 2000 条），可在设置中一键清空。无统计上报、无埋点、无账号体系、不加载任何外部 JavaScript。代码为明文可读，内联的 MD5 实现依据 RFC 1321 自行编写，未引入第三方库。

## 常见问题

- **没有译文**：确认脚本已启用、`@connect` 已授权；看设置面板顶部的识别结论；按 `Alt+Enter` 强制翻译一次。
- **提示 411 / 频率受限**：有道接口限流，脚本会自动退避重试，连续失败暂停 30 秒并显示倒计时，**冷却结束自动继续翻译**；急需可切百度或本地源。
- **往下滑就不翻译了**：1.3.0 已修复。滚动会自动补扫漏翻段落；超长页面、折叠内容、验证页后加载的正文都会补上。若状态显示「限流中 Ns」，等倒计时结束即可，或按 `Alt+Enter` 立即补一次。
- **Cloudflare 验证页不翻译**：验证页的中文占位文字不再被误判为中文站，正文出现后自动重判翻译。
- **中文网站不翻译**：这是默认行为，按 `Alt+Enter` 可强制翻译，或把运行范围改为「所有网站」。
- **部分段落没翻**：段落级过滤会跳过过短文本、含中文的文本、URL/邮箱、代码特征文本以及导航/页脚/代码块，可在设置里调小「最短段落」。
- **译文错位**：点「清除本页译文」后重新 `Alt+Enter`。
- **图标看着太淡 / 半透明**：这是 1.5.0 起的默认设计，避免遮挡网页内容；鼠标移上去或展开设置面板时会自动变清晰，功能与点击区域完全不变。
